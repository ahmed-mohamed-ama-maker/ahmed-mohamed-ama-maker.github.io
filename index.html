Ahmad Publisher

Uses YouTube API Services (YouTube Data API v3).

Ahmad Publisher is a private, internal tool used only by Ahmed Mohamed to upload his own videos to his own YouTube channels (AME, Athar, Toasty). Ahmed makes every video himself; the tool only uploads the finished file and sets its title, description, tags and thumbnail.

Privacy Policy

What data we access: through the YouTube Data API, the tool accesses only the YouTube channels owned by Ahmed Mohamed, with the scopes youtube.upload and youtube.readonly. It uploads videos and reads basic channel info (channel name and ID) to confirm the right channel.

What we store: OAuth tokens are stored only on the owner's own computer. No data is sent to any other server, sold, shared with third parties, or used for advertising. The tool does not access any other user's data.

Deleting data: access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the local token files removes all stored data.

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
